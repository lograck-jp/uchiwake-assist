# 内訳アシスト（Excel アドイン）

保温工事の見積書「内訳」シートの入力を助ける Excel アドインです。

- 入力：品目 → 室 → 仕様（角ダクト・BOX は寸法）を選ぶと、選んでいる行に仕様の行を書く
- 自動入力：内訳の E列にサイズを打つと、保温厚・単位・見積単価（参照元は Y〜AB列）が入る
- 選択行に単価：選んでいる行（離れた範囲も可）の見積単価を入れ直す
- 計・経費：A/B/C列 集計・小計・工事費計・合計・出精値引き、経費（資材運搬交通費・諸経費・法定福利費）
- 単価ルール：協会単価に無いもの（GV 50A以下＝直管×1.1、フレックス継手＝直管×0.8 など）を画面で追加・編集

- 公開先：https://lograck-jp.github.io/uchiwake-assist/
- 作業ウィンドウ：`taskpane.html`（`taskpane.js` / `core.js` / `taskpane.css`）
- Excel 登録用：`manifest.xml`
- 設定マスタ（選択肢・仕様候補・単価履歴）は利用者のパソコンの Excel ファイルから読み込みます。このリポジトリには単価などのデータは入っていません。
- 導入手順は「内訳アシスト_導入手順.html」を参照してください。

## ファイル
| ファイル | 役割 |
|---|---|
| taskpane.html / .css / .js | 作業ウィンドウの画面と Excel への書き込み |
| core.js | 内訳シートの解析、登録位置の計算（Excel に依存しない部分） |
| commands.html | リボンボタン用（中身は空） |
| manifest.xml | Excel にアドインを登録するための設定ファイル |
| assets/ | アイコン |
| （単価表） | 保温積算資料の .xlsx はパソコン側で読み込む。このリポジトリには入れない |
| lib/xlsx.full.min.js | 設定マスタ（.xlsx）を読むためのライブラリ（SheetJS、Apache-2.0） |
| v1/ | 前の版（v1.3.2）。メニュー「前の版の画面を開く」から使える |

## 更新するとき
ファイルを差し替えたら、`taskpane.html` の `?v=2.0.2` の数字を上げてからアップロードします（Excel 側の古い読み込みを避けるため）。


## 更新履歴
- 2.0.2（2026/10/24）工事費 計の直し：小計を入れた大項目は小計を、集計だけの大項目は集計を合計する（ほかの計に入っている計は足さない）。同じ大項目で A列の集計を何度か入れて小計した見積で、最初の集計だけを拾っていたのを直した。どの計にも入っていない明細があれば知らせる。小計も同じ考え方にして、=SUM(J272) のような1つだけの計が漏れないようにした。
- 2.0.1（2026/10/24）書き込む行か次の行にデータがあれば、行を挿入して書く（挿入する行数はパネルで指定、挿入行は内訳(FMT)の A〜J列の書式）。仕様の名前を1行に詰めて表示。仕様の候補を ↑↓ で並べ替え（このパソコンに記憶）。BOX・チャンバーは D列に名前（SAダクトなど）、次の行の E列に3辺の寸法を書き、W・H・L・記号を個別に出す/出さないを切り替え。角ダクトは寸法の入力をなくした（数量だけ、空欄可）。角ダクト・BOX の保温厚は 25・50 と「ほか」の手入力。
- 2.0.0（2026/10/24）入力画面を作り直し。品目 → 室 → 仕様を1つ選ぶごとにたたみ、選んでいる行に仕様の行を書く（角ダクト・BOX は寸法も）。E列にサイズを打つと保温厚・単位・単価・参照元を自動で入れる。選択行に単価（離れた範囲も可）。単価ルール（GV 50A以下＝直管×1.1、丸ダクトのフレックス継手＝直管×0.8。画面で追加・編集）。計・経費タブ（A/B/C列 集計・小計・工事費計・合計・出精値引き＝見積書の VBA「集計」を移植して不具合を修正、経費の自動作成）。前の版は v1/ に残した。
- 1.3.2（2026/10/08）パネルの背景を黒に戻す（白は内訳シートと同じ色で見分けにくいため）。エルボの直しはそのまま。
- 1.3.1（2026/10/08）パネルの背景を白に（色は taskpane.css の先頭でまとめて変えられる）。エルボの式は範囲が変わるときだけ書き直す。
