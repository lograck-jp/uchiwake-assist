# 内訳アシスト（Excel アドイン）

保温工事の見積書「内訳」シートの入力を助ける Excel アドインです。

- 入力：品目 → 室 → 仕様（角ダクト・BOX は寸法）を選ぶと、選んでいる行に仕様の行を書く
- 自動入力：内訳の E列にサイズを打つと、保温厚・単位・見積単価（参照元は Y〜AB列）が入る
- 選択行に単価：選んでいる行（離れた範囲も可）の見積単価を入れ直す
- 計・経費：集計・小計・工事費計・合計・出精値引き、経費の行（経費の下に合計も入れる）
- 見積条件：設定マスタに登録した見積条件の文章から選んで、内訳の最後に「一、…」の行を入れる
- 単価ルール：単価表に無いものを「基準の単価×係数」で出すルールを画面で追加・編集

## データの置き場所
- このリポジトリにあるのはプログラムだけです。単価・単価表・率・係数・仕様と単価表の対応・見積条件の文章などの数字や決まりごとは入っていません。
- それらは利用者のパソコンにある「設定マスタ」（Excel ファイル）と単価表から読み込み、そのパソコンの中にだけ記憶します。
- アドインは開いている見積書だけを読み書きし、外部へデータを送りません。

## ファイル
| ファイル | 役割 |
|---|---|
| taskpane.html / .css / .js | 作業ウィンドウの画面と Excel への書き込み |
| core.js | 内訳シートの解析、登録位置・計の計算（Excel に依存しない部分） |
| commands.html | リボンボタン用（中身は空） |
| manifest.xml | Excel にアドインを登録するための設定ファイル |
| assets/ | アイコン |
| lib/xlsx.full.min.js | 設定マスタ（.xlsx）を読むためのライブラリ（SheetJS、Apache-2.0） |
| v1/ | 前の版の画面。メニュー「前の版の画面を開く」から使える |

## 更新するとき
ファイルを差し替えたら、`taskpane.html` の `?v=2.0.16` の数字を上げてからアップロードします（Excel 側の古い読み込みを避けるため）。

## 更新履歴
- 2.0.16（2026/10/26）BOX の E列は3辺とも書き、記号（W・H・D・L）は辺ごとに数字の後に付けるかを選ぶようにした。
- 2.0.15（2026/10/26）BOX・チャンバーの寸法：記号（W・H・D・L）と並びを選べるようにした。記号は数字の前でも後ろでもよく、記号なしの寸法は選んだ並びで読む。
- 2.0.14（2026/10/26）見積条件のタブを追加。経費を入れるときに合計も入れるようにした。
- 2.0.13（2026/10/25）率・係数・対応表などの数字をプログラムから外し、設定マスタからだけ読むようにした（設定マスタの読み直しが必要）。
- 2.0.0〜2.0.12（2026/10/24〜25）入力画面の作り直し、自動入力、選択行に単価、単価ルール、計・経費、エルボ・MD継手の行、行の挿入など。
- 1.0.0〜1.3.2（2026/09/28〜10/08）初版と改良（前の版の画面。v1/ に残してある）。
