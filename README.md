# 内訳アシスト（Excel アドイン）

保温工事の見積書「内訳」シートに、品目・施工箇所・仕様・サイズを選んで明細を登録する Excel アドインです。

- 公開先：https://lograck-jp.github.io/uchiwake-assist/
- 作業ウィンドウ：`taskpane.html`（`taskpane.js` / `core.js` / `taskpane.css`）
- Excel 登録用：`manifest.xml`
- 設定マスタ（選択肢・仕様候補・単価履歴）は利用者のパソコンの Excel ファイルから読み込みます。このリポジトリには単価などのデータは入っていません。
- 導入手順は「内訳アシスト_導入手順.html」を参照してください。

## ファイル
| ファイル | 役割 |
|---|---|
| taskpane.html / .css / .js | 作業ウィンドウの画面と Excel への書き込み |
| core.js | 内訳シートの解析、登録位置の計算（Excel に依存しない部分） |
| commands.html | リボンボタン用（中身は空） |
| manifest.xml | Excel にアドインを登録するための設定ファイル |
| assets/ | アイコン |
| （単価表） | 保温積算資料の .xlsx はパソコン側で読み込む。このリポジトリには入れない |
| lib/xlsx.full.min.js | 設定マスタ（.xlsx）を読むためのライブラリ（SheetJS、Apache-2.0） |

## 更新するとき
ファイルを差し替えたら、`taskpane.html` の `?v=1.3.1` の数字を上げてからアップロードします（Excel 側の古い読み込みを避けるため）。


## 更新履歴
- 1.3.1（2026/10/08）パネルの背景を白に（色は taskpane.css の先頭でまとめて変えられる）。エルボの式は範囲が変わるときだけ書き直す。
- 1.3.0（2026/10/06）単価は協会単価（保温積算資料）だけから取る（過去見積・手入力の記録は使わない）。ステンレス管（D列 SUS・Su サイズ。単価は同じ外径の鋼管で引く）。バルブ類・フランジ類は種類とサイズだけ選び、数量は空欄・保温厚は配管から（25以下→25、50以下→50）・仕様は配管の仕様。エルボ 1式（J列＝ROUNDUP(直管の合計×0.35,-1)）。大項目なしで施工箇所・仕様から書ける。D列は中央揃え、仕様の行の J列は式なし。
- 1.2.2（2026/10/05）登録先の「入れ方」を選べるように（下に追加＝既定・今ある行は変えない／数量を足す／行を指定。行を指定は Excel で選んだ行も使える）。既定では今ある行の数量や D列を書き換えない。
- 1.2.1（2026/10/05）「位置を確認」で書き込む行すべてを選択するよう修正。仕様の候補を「保温材｜外装・仕上げ」の2列にそろえた表示にし、回数や表番号は出さないように。固定・直す・外すは「候補を編集」のときだけ表示。
- 1.2.0（2026/10/05）大項目の番号を自動に。仕様の候補を「この見積書で使用中」優先・保温材の色分け表示に変更し、パネルで固定・編集・追加・非表示ができるように（民間／官庁の切り替え付き）。保温厚のボタンを追加。サイズを押しても画面が動かないように。Enter は登録せず数量欄の移動（Ctrl＋Enter で前へ）。仕様のセルは左揃え・サイズは右揃え。系統計・大項目計は作らない。
- 1.1.0（2026/10/05）単価を「保温積算資料（令和8年度版）」の表から取るようにした。仕様と表の対応は設定マスタの M_積算資料対応、加算は M_単価加算。新しく書いた明細の Y〜AB 列に参照元（§・表番号）・仕様・サイズ・厚みを書く（列の挿入はしない）。
- 1.0.1（2026/10/02）サイズ選択中にカーソルが単価欄へ移らないよう修正。Tab は数量→次のサイズの数量へ。単価未登録の欄は点線表示。
